# Security

The arcade runs inside Claude Code on your machine, so a security problem
here matters.

## Reporting a problem

Please report it privately, not in a public issue:
[open a private report](https://github.com/Zaho92/claude-arcade/security/advisories/new)
("Report a vulnerability" under the Security tab).

Say what you found and how to see it happen. This is a hobby project with one
maintainer; I read reports as soon as I can and will tell you what I make of
yours.

## Supported versions

Only the newest version gets fixes. Installations follow `main`, so
`claude plugin update` brings you there. A fix is a new version, never a
change to one already released.
